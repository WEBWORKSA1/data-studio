How to use the pivot table

A pivot table groups rows that share a value and summarises a measure for each group. Pick a Rows field (for example Region), an optional Columns field (for example Quarter), and a Values field with an aggregate (for example Sum of Revenue). Grand totals are calculated from the underlying rows, so averages and distinct counts stay correct. They are never an average of averages.

  • Count counts non-empty values. Use it with any field to count records.
  • Distinct count counts unique values, such as unique customers per region.
  • Numbers formatted with currency symbols or thousands separators (like $1,200) are understood automatically.
