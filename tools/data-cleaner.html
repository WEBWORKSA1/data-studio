Cleaning steps

Why these steps matter

Most "wrong numbers" in reports aren't maths errors. They're data-entry noise. "Canada" and "Canada " group separately in a pivot table. A pasted row counted twice inflates revenue. N/A typed into a numeric column turns the whole column into text. The cleaner fixes these patterns in one pass and tells you exactly what changed.

  • Order of operations: nulls are standardised and spaces trimmed before duplicates are detected, so near-duplicates that differ only by whitespace are caught.
  • Case changes apply only to text values. Numbers and dates are left untouched.
  • Regex find & replace uses JavaScript syntax with the global flag, for example \D → empty to strip non-digits from phone numbers.
