What the profiler checks

  • Type inference. Each column is classified as numeric, date, boolean or text, based on at least 90% of its non-empty values.
  • Completeness. Missing values are counted per column and across the whole table. Blank strings and common null tokens (NA, N/A, null, -) count as missing.
  • Uniqueness. Distinct counts reveal ID columns (100% unique) and low-cardinality categories. Exact duplicate rows are counted for the table.
  • Distribution. Numeric columns get min, quartiles, median, mean, standard deviation, max and a histogram. Values beyond 1.5× the interquartile range are flagged as potential outliers.
  • Top values. Text columns show their most frequent values, which is great for spotting typos like "New York" vs "new york ".
